# 奶蛙大战奶龙 🐸🐉

一个参考《植物大战僵尸》的**网页**横版塔防小游戏：奶蛙守住后院草坪，奶龙从右边的洞穴一波波冲过来。

打开网页就能玩，**手机、平板、电脑都行**（横屏更舒服，可以全屏、可以装到桌面离线开局）。
纯前端实现，**零第三方依赖**（Canvas 2D 手绘美术 + WebAudio 合成音效），所有角色都是用代码画出来的，没有任何图片和音频文件，整个游戏就是一堆静态文件。

---

## 一、怎么让所有人都能玩到

游戏是纯静态网站，**任何静态托管都能放**，不需要服务器、不需要数据库。

### 方式 A：GitHub Pages（推荐，本仓库已经配好）

1. 把项目推到 GitHub 仓库（默认分支 `main`）。
2. 打开仓库 **Settings → Pages → Build and deployment → Source**，选 **GitHub Actions**。
3. 以后每次 push 到 `main`，`.github/workflows/pages.yml` 会自动跑一遍自测并发布。

发布完的网址长这样（**别人直接打开就能玩，手机电脑都一样**）：

```
https://<你的用户名>.github.io/<仓库名>/
```

所有路径都是相对路径，放在子目录里也不会白屏。

### 方式 B：Cloudflare Pages / Netlify / Vercel

三个平台都是免费静态托管，不用改任何代码：

| 平台 | 怎么放 |
| --- | --- |
| Cloudflare Pages | 连接到 Git 仓库，**构建命令留空**，输出目录填 `/`（根目录） |
| Netlify | 拖拽整个文件夹到 Netlify Drop，或者连仓库，同样不需要构建命令 |
| Vercel | 「Other」框架预设，Build Command 留空，Output Directory 填 `.` |

> 注意：**不要**选 Node 服务端渲染之类的预设，这个项目没有构建步骤。

### 方式 C：拿自己的电脑当服务器（同一 Wi-Fi 就能玩）

```bash
npm start
```

终端会直接打印两个地址：

```
电脑上玩：   http://localhost:5173/
手机/平板玩：http://192.168.x.x:5173/     ← 手机连同一个 Wi-Fi，输入这个
```

手机上横屏 + 点「全屏」，就跟原生小游戏差不多了。

### 装到桌面 / 断网也能玩

页面带了 PWA 支持：用 Chrome / Edge / 安卓浏览器打开后，右下会提示「装到桌面」；
iOS Safari 用「分享 → 添加到主屏幕」。装好之后**断网也能开局**（Service Worker 会把整套游戏缓存下来）。

## 二、玩法

| 操作 | 说明 |
| --- | --- |
| 点卡片 → 点草坪 | 种下奶蛙（也可以按住卡片拖到草坪上） |
| 同格再放同款卡 | **合成升级**，最高 ★★★ |
| 点奶瓶 | 收奶（默认开了自动收奶，可以在右上角关掉） |
| 点左上角奶量框 | 一键收下场上所有奶瓶 |
| 点底部「奶浪」条 / `Q` | 释放**奶怒大招「奶浪」**（奶怒攒满才亮） |
| 点天气条 | 看当前昼夜 / 天气到底改了什么数值 |
| 铲子按钮 / `S` | 移除奶蛙，返还 40% 奶 |
| `1`~`7` | 快速选卡 |
| `空格` / `P` | 暂停 |
| `Esc` | 取消选择 |
| 右上角按钮 | 暂停、2 倍速、音效、自动收奶、铲子、重来 |
| 底部工具条 | 复制本局链接、每日挑战、装到桌面、全屏 |

**目标**：撑过全部波次（第 10 / 11 波末尾有奶龙王）。任何一只奶龙走到最左边、而且那一行的推车已经用掉，就失败。

### 奶蛙（防守方）

| 名字 | 奶 | 冷却 | 作用 |
| --- | --- | --- | --- |
| 奶牛蛙 | 50 | 5s | 每 8 秒产 25 奶 |
| 奶瓶蛙 | 100 | 5s | 单发 20 伤害 |
| 奶罐墙 | 50 | 20s | 2000 血肉盾 |
| 冰镇蛙 | 175 | 8s | 伤害 + 减速 55%，持续 3.5 秒 |
| 双管蛙 | 200 | 8s | 一次连喷两发 |
| 三头蛙 | 325 | 10s | 同时打自己这行和上下两行 |
| 奶泡炸弹 | 150 | 25s | 放下 1.1 秒后炸开，范围内 1800 伤害 |

### 奶龙（进攻方）

| 名字 | 血量 | 速度 | 特点 |
| --- | --- | --- | --- |
| 小奶龙 | 200 | 20 | 基础款 |
| 冲刺龙 | 180 | 46 | 跑得快、很脆 |
| 纸杯龙 | 560 | 19 | 头顶纸杯，更耐打 |
| 铁盔龙 | 1180 | 17 | 铁奶桶头盔，咬得更疼 |
| 奶龙王 | 4200 | 13 | 最终 boss，正面硬啃奶罐 |

### 关卡

1. **第 1 关 · 后院奶场**：10 波，节奏舒缓，只出晴 / 奶雨 / 狂风，也不开奶龙合体 —— 用来熟悉经济。
2. **第 2 关 · 奶龙压境**：11 波，血量 ×1.1、移速 ×1.06，四种天气全开、精英和合体都会出现，最后两波各有一个奶龙王。
3. **第 3 关 · 无尽奶潮**：波次无限，越往后越强，按击杀和波次计分，最高分记在 localStorage。

每行左边有一台**吸奶推车**，奶龙逼近时会自动冲出去清掉这一行，每行只能用一次。

## 三、《植物大战僵尸》里没有的东西

这一版专门加了一批 PvZ 没有的机制，目的只有一个：**每一局都不一样，而且玩家有主动的事可做**。

| 机制 | 说明 |
| --- | --- |
| **奶蛙合成升级** | 同一格再放一张同款卡就升一级，最高 ★★★（伤害 ×1.95、射速更快、血更厚）。滚雪球被刻意压住：产奶的收益最小 |
| **奶怒大招「奶浪」** | 击杀攒怒气，攒满由玩家手动放一次全屏伤害 + 冻结。PvZ 全程只有被动布置，这里是主动技能层 |
| **特殊地块** | 每关随机撒几块「奶泉地（产奶 +40%）」「冰晶地（射速 +15%，奶柱自带减速）」，站上去才有加成 |
| **昼夜循环** | 一局之内清晨 → 正午 → 黄昏 → 夜晚循环，产奶 / 射速 / 伤害 / 移速 / 减速强度全都跟着变 |
| **天气系统** | 晴 / 奶雨 / 浓雾 / 狂风，约半分钟随机切换，都是**有得有失**的取舍（比如奶雨多产奶但伤害 -12%，浓雾砍掉射手 28% 射程） |
| **精英词缀** | 部分奶龙头顶带光环出场：**奶盾**（先破盾）、**狂暴**（残血变快变凶）、**吸血**（啃奶蛙回血）、**分裂**（倒下裂成两只）、**迅捷**（更快更小）。一波有硬上限，不会铺满全场 |
| **奶龙合体** | 同种奶龙在同一行撞到一起会合成多头巨型：更厚、咬得更狠。关键设计是**只把两只剩余血量相加、不补血** —— 提前打伤一只，合体出来就是残血巨兽。要不要让它合，是玩家的真实取舍 |
| **每日挑战 + 分享链接** | 点底部「每日挑战」用当天日期当种子，**全世界当天是同一套地形 / 天气 / 精英 / 合体点**，可以比分数；点「复制本局链接」把 `?seed=...&level=...` 发给朋友，对方打开就是一模一样的一局 |
| **奶龙吞噬成长** | 奶龙啃掉一个奶蛙就变强一层（最多 3 层），所以「用奶蛙换时间」是有代价的 |
| **冰霜叠层** | 冰奶柱命中会叠冰霜，叠满 3 层直接冻结（奶龙王免疫冻结，只会被重减速） |

想把某一局发给别人、或者自己复现，也可以直接改网址：

```
?level=2            直接开第 2 关
?seed=123456        固定种子（地形 / 天气 / 精英词缀都由它决定）
?daily=1            当天日期当种子（= 每日挑战）
?level=2&seed=123456  两个一起用，就是「别人打开也是这一局」
```

## 四、多设备上做了哪些适配

- **一份 1280×800 的画布自动缩放**（letterbox），横屏铺满、竖屏也不会变形；手机竖屏会提示「把手机横过来」并一键全屏 + 锁横屏。
- **指针事件统一鼠标 / 触摸**，支持点按和拖拽种植；画布上关掉了浏览器手势，不会误触缩放和下拉刷新。
- **刘海屏 / 圆角屏安全区**（`viewport-fit=cover` + `env(safe-area-inset-*)`）。
- **底部工具条不覆盖草坪**：全屏、装到桌面、复制链接、每日挑战都放在画布下方的工具栏里，手里拿着手机也点得到。
- **性能**：粒子数量有上限，DPR 限制在 2 以内，老手机也不至于掉帧。
- **离线**：Service Worker 缓存整套游戏，装到桌面后断网也能玩。

## 五、目录结构

```
index.html            页面、画布、底部工具条
styles.css            页面样式（自适应缩放 + 安全区）
manifest.webmanifest  PWA 配置（装到桌面）
sw.js                 Service Worker（离线缓存清单）
server.mjs            零依赖静态服务（会打印局域网地址，方便手机连）
start.cmd             Windows 一键启动
.github/workflows/    GitHub Pages 自动发布
src/core/             纯逻辑层，不碰 DOM，可在 Node 里跑
  config.js           所有数值：网格、奶蛙/奶龙属性、经济、昼夜/天气/精英/合体参数
  level.js            关卡与波次表（含无尽模式生成器、特殊地块）
  state.js            游戏状态 + 玩家动作 + 随机种子（每日挑战 / 分享链接的基础）
  update.js           每帧模拟：经济、战斗、波次、推车、胜负判定
  weather.js          昼夜循环 + 天气切换（全场倍率的来源）
  affix.js            精英词缀：奶盾 / 狂暴 / 吸血 / 分裂 / 迅捷
  fuse.js             奶龙合体进化（多头巨型）
  stats.js            有效数值：合成等级 + 特殊地块 + 昼夜天气一起折算
  layout.js           HUD 与弹窗布局（绘制和点击命中共用一份数据）
src/render/
  sprites.js          程序化美术：奶蛙、奶龙、奶罐、炸弹、推车
  draw.js             场景合成、天气特效、HUD、覆盖层
src/app/
  input.js            指针/键盘 → 逻辑坐标
  audio.js            WebAudio 合成音效（含天气 / 合体 / 精英提示音）
  shell.js            页面外壳：Service Worker、全屏、装到桌面、竖屏提示、分享按钮
  main.js             控制器与主循环
tools/
  selftest.mjs        无头自测（含脚本 AI 打完整关卡、离线清单检查）
  simulate.mjs        跑一局并打印逐波战报
  balance.mjs         同一关跑很多次，看平均难度
  ai.mjs              脚本 AI（同时用于验证数值可玩性）
  preview.html        场景预览页：不玩整局，直接看任意场景的渲染（美术调试）
```

## 六、测试

```bash
npm test                        # 39 项无头自测
node tools/simulate.mjs 1 900   # 用脚本 AI 打第 1 关，打印逐波战报
node tools/simulate.mjs 2 900   # 第 2 关（昼夜 / 天气 / 精英 / 合体全开）
node tools/simulate.mjs 3 600   # 无尽模式
```

`npm test` 覆盖：配置一致性、种植 / 冷却 / 占位、铲子返还、产奶与天上掉奶、点击收奶、开火击杀、
减速、炸弹范围、啃咬、推车启动、完全不防守必输、脚本 AI 能通关第 1 / 第 2 关、无尽长跑数值健康、
界面布局不重叠，以及：

- **昼夜**会推进并真的改变倍率；
- **天气**会自己换，奶雨多产奶、浓雾砍射程、夜晚减产；
- **精英**：护盾先吃伤害、狂暴 / 吸血 / 迅捷数值生效、分裂变两只且不计分；
- **合体**：血量相加不补血、一波只合一次、第 1 关不开；
- **同一个种子 = 同一局**（每日挑战和分享链接的基础）；
- **网站化**：manifest 用相对路径、离线清单覆盖全部源码模块、页面适配各设备。

> 当前数值：第 1 关脚本 AI 277 秒通关；第 2 关（全机制开启）351 秒通关，推车剩 3；
> 无尽模式大约能撑到第 12 波，分数 2310 上下。

### 看渲染不用先玩一局

```bash
npm start
# 然后打开 http://localhost:5173/tools/preview.html
```

一键切换菜单、三关对局、暂停、胜利、失败六个场景，走的都是正式渲染管线；也支持

## 七、想改数值？

都在 `src/core/config.js`（单位属性、经济、昼夜 / 天气 / 精英 / 合体参数）和 `src/core/level.js`（波次表、每关开哪些机制）。
改完跑一次 `npm test`，脚本 AI 会告诉你难度是不是还合理：它胜出时剩余推车越多，说明这一关越轻松；
第 2 关的模拟还会顺便打印精英和合体触发了多少次。
